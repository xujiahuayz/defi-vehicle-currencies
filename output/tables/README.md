# Generated Tables

This directory contains TeX fragments and matching inspection PDFs. It is not the index of tables in the current manuscript: the manuscript presently defines its 12 empirical tables inline, and neither the paper nor the deck inputs a file from this directory.

The four named `scripts/tabulate/render_*.py` owners and the live manuscript lineage are mapped in [`../../scripts/tabulate/README.md`](../../scripts/tabulate/README.md). Other files here are older analysis outputs with no current deliverable consumer unless that mapping says otherwise. Do not infer currency from a filename or modification time.

New runs through `write_table_artifacts` write provenance sidecars under `data/manifests/output/tables/`. Existing files without a matching current sidecar are unstamped inspection history, not quantitative authority. Edit a named producer rather than its rendered fragment. See the [canonical repository and data map](../../docs/repository-data-map.md#output-layers).
