# Phase 2 — candidate framing generation

Loop-until-dry, blind generation (each attempt did not see prior attempts, to avoid correlated-generation risk). Result: **1 framing accepted, 3 total attempts, stopped by loop-until-dry** (two consecutive non-novel attempts), not by hitting the backstop cap of 5.

Attempts 2 and 3 were independently generated from scratch and independently judged non-novel against framing #1 — both reproduced the same headline mechanism (Krugman 1980's transaction-cost vehicle-selection logic implemented inside an AMM, microfounded by Lehár & Parlour's 2024 pool-depth/price-impact comparative statics) and the same architecture/persistence channel (Caparros, Chaudhary & Klein 2024's gas-cost → repositioning → concentration causal design, extended to vehicle-candidate pools), just relabeled. This reads as genuine convergence given the actual evidence base and literature in hand, not as the generator running out of ideas after one real attempt — full novelty-check reasoning for both rejections is in the workflow journal if it needs re-auditing.
