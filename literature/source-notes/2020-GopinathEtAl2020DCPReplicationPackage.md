# Gopinath et al. (2020) replication package

- Source set: `GopinathEtAl2020DCP`
- Official package: openICPSR DOI `10.3886/E111161V1`, version 1 released 28 February 2020 under CC BY 4.0. The official inventory contains 86 files in 31 folders and reports about 549.6 MiB across model, global and firm-level code and data, a README and disclosures.
- Public inspection bundle: `literature/papers/2020-GopinathEtAl2020DCPReplicationPublicInspection-supplement-openicpsr-v1.tar.gz`
- 26,256 bytes. This locally assembled bundle preserves the official inventory, README, disclosure, retrieval state and public previews of the main global, model and firm-level scripts. It is not the deposited 550 MiB archive and is not represented as publisher-byte-identical.
- Access disposition: the AEA replication link resolves to the openICPSR project. Project, folder and file download routes require login; direct binary endpoints returned Cloudflare 403. UCL institutional authentication reached ICPSR account completion but required a new account and email verification, an external action that was not initiated. Exact full-package bytes and member hashes therefore remain account-gated.
- Inventory and workflow: the deposit lists 27 Stata do-files, 27 Matlab files, six Dynare model files, six Stata data files, five workbooks, three CSVs, three PDFs, eight text files and one ado file. The README covers the article and online appendix. Model and global pipelines use Matlab R2019a, Stata 15 and Dynare, and name the Stata dependencies; the main global scripts map to Tables 2 to 5 and 10 to 19 and Figures 4 to 8 and 14 to 23. The README labels the global unit-value source `Compustat`, but the paper, code paths and deposited inputs identify UN Comtrade; treat the README label as a documentation error.
- Reproduction limit: confidential Colombian transaction data are excluded under central-bank, tax and statistics-agency agreements. Figure 10, Tables 6, 7 and 20 to 24, the top two rows of Table 27 and related micro regressions therefore cannot be publicly rerun. Model-based Figures 11 to 13 and Tables 8, 9, 26 and 27 otherwise use deposited aggregate inputs and code. The code hard-codes local Dynare paths, which prevents portable execution without edits.
- Scientific scope: describe this source as having global and model replication code and data deposited, with firm-level code disclosed but proprietary inputs unavailable. Do not call the full article end-to-end publicly reproducible. A separate AEA ZIP inspected during discovery contains six author disclosure statements and is not a replication package.
- Disposition: the full declared non-text companion is unavailable without ICPSR account completion; the bounded public inspection bundle is saved byte-identically in the evidence worktree and primary project checkout. No correction or corrigendum was identified in dated AEA, Crossref and NBER checks through 2026-08-09.
