# Liu, Makarov and Schoar Terra replication package

The canonical non-text artifact is Mendeley Data version 4, published 2026-08-03 under DOI 10.17632/j5d8n7hzdy.4. The saved ZIP is 97,835,184 bytes with version 3 is superseded and was not retained.

The package contains processed data and code for fourteen main figures, five Internet Appendix figures, three main tables, two Internet Appendix tables and static Table A.1. It does not contain every raw research input, and the accepted manuscript remains restricted. A full code-and-data audit found a material label mismatch: Tables 2 and 3 call the size variable pre-run balance, but the generating code bins and regresses on `full_maxusd`, the wallet's peak aUST balance during 6 to 13 May. The shipped panel also contains `prerun_usd`, which is not used. Replacing the peak measure with the actual pre-run measure changes 16.93 percent of 159,669 wallet bins, changes the controlled log-size coefficient from -4.531 with R-squared 0.084 to -6.058 with R-squared 0.122, and changes the largest-bin mean loss from 50.61 percent to 25.05 percent. The defect limits investor-heterogeneity claims but does not invalidate the reflexive run mechanism used by this project.
