# Somogyi (2026) replication package

- Source set: `Somogyi2026DollarDominanceFX`
- Artifact: exact publisher ZIP served from the INFORMS supplement handoff for DOI `10.1287/mnsc.2024.07656`, last modified 25 March 2026
- Verified file: `literature/papers/2026-Somogyi2026DollarDominanceFXReplicationPackage-supplement-informs.zip`
- 5,164,152,397 bytes. ZIP integrity passes with 637 entries and 583 files totaling 13,840,524,383 uncompressed bytes.
- Inventory: 458 CSV files, 110 Matlab files, 14 XLSX files and one README PDF. The data footprint includes about 12 GB of pseudo Olsen quotes, 714 MB of pseudo CLS order flow and 120 MB of pseudo CLS volume, plus pseudo Bloomberg fields and public or hand-collected auxiliaries.
- Environment: the README specifies Matlab R2024a and Parallel Computing, Econometrics, Optimization and Statistics toolboxes and estimates a two-hour run, but provides no environment lock. No Matlab or Octave runtime was available for live execution in this audit.
- Reproduction boundary: confidential CLS, Olsen and several Bloomberg inputs are absent and replaced with size- and shape-matched pseudo data. The public package tests execution and interface flow but cannot numerically reproduce the 12.6 percent or eight-billion-dollar holiday estimate or the C1 to C3 results. The README says only parts of Figure 1 are fully reproducible. Default pseudo inputs are fixed and the active path is deterministic, while pseudo-generation and bootstrap branches are inactive.
- Coverage: the code produces all nine main-paper exhibits, Tables 1 to 4 and Figures 1 to 5, plus Appendix Figure D.1 and Table D.4. It does not produce the other 17 Appendix D exhibits. No saved benchmark outputs or numerical assertions are supplied, and output filenames are not watermarked as pseudo. CLS pseudo source filenames also omit the pseudo label, creating a material risk of misinterpretation.
- Inference defect: the custom two-way-cluster degrees-of-freedom correction in `PanelClass.robustse` applies Matlab matrix right-division to the vector of cluster counts. With 15 triplets and roughly 2,586 dates this evaluates near 1.00039, effectively retaining only the date-cluster adjustment instead of the 15/14 triplet correction. Table 4's 15-cluster t-statistics, including marginal C2 and C3 results around 2.04 to 2.33, should be re-estimated in a standard package with small-cluster-robust or wild-cluster inference.
- Other code risks: seven active actual-data branches contain author-specific absolute paths; control forward-filling has no gap cap; custom covariance code uses explicit matrix inversion; and no benchmark comparison, correction or corrigendum was found.
- Scientific scope: the source supports auditing program coverage, interfaces and the logic of the holiday and dominance calculations. It does not independently reproduce proprietary-data estimates or upgrade the holiday exclusion and 15-triplet panels to causal identification.
- Disposition: non-text companion preserved as the exact publisher byte stream in the evidence worktree and primary project checkout and inspected at archive, member, environment, data-substitution, exhibit-coverage, numerical-inference and claim levels; it receives no paper card of its own
