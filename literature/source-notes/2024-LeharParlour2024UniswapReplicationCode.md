# Lehar and Parlour (2024) replication package

- Source set: `LeharParlour2024Uniswap`
- Artifact: official Journal of Finance Supporting Information file `jofi13405-sup-0001-ReplicationCode.zip`, retrieved from the Wiley supplement endpoint in an authenticated publisher browser session after unauthenticated HTTP clients returned access-denied responses
- Verified file: `literature/papers/2024-LeharParlour2024UniswapReplicationCode-supplement-replication-code.zip`
- SHA-256: `10c396148575b4f11a666aaf2ac7898c20ea5e2f9558e7d10bf1ca424d52456e`
- Size and integrity: 2,033,280 bytes; `unzip -t` passes; nine files expand to 6,413,885 bytes
- Inventory: three scripts, `AlayzeUniswapDataJF.jl` (1,874 lines), `analyzeBinanceDataJF.jl` (535 lines), and `UniswapJF.do` (535 lines), plus six CSV files. The CSVs contain 1,548 exchange rows, 11,004 Uniswap-event rows, 242 ETH/USDT rows, 4,422 Binance rows, 2,148 Binance-symbol metadata rows, and 52 matched-symbol rows.
- Scientific scope: the Julia code documents the token-address definitions, WETH/stablecoin conversion, flash-swap handling, pool construction, block/day aggregation, liquidity-flow and price-impact measures, and the random-sampling steps used to construct the supplied excerpts. The Stata code exposes the pool-size specifications, pool and date fixed effects, two-way clustering, winsorization, Binance-versus-Uniswap price-impact comparisons, PancakeSwap timing indicator, daily fee/gas regressions, and several sample restrictions. No theory or numerical code for the equilibrium propositions or the displayed omega formula is present, so the package cannot resolve the article's apparent omega-definition inconsistency.
- Reproduction limit: this is an audit package, not an end-to-end reproduction bundle. The scripts use absolute author-machine paths, mutate the package environment with unpinned `Pkg.add` calls, call an omitted `LatexDef.jl` helper and an omitted authentication file, and depend on absent inputs including `labeled_tokens.csv`, `dfNoGapPanel.csv`, `dfNoGapPanelx.csv`, `binancemerged.csv`, `dfdailyret.csv`, `exchangeV3.csv`, and `uniswapV5.csv`. The supplied Uniswap and Binance files are explicitly generated as 1-in-10,000 samples and therefore cannot reproduce the article's 94,232,292-transaction panel or final tables. The package makes the measurement and estimation pipeline more auditable but does not independently reproduce the reported estimates.
- Disposition: non-text companion, saved byte-identically in the evidence worktree and primary project checkout and inspected at the archive, file, variable, code-path, specification, dependency, and missing-input levels; it receives no separate paper card
