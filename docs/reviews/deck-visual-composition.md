# Deck visual composition audit

Status: temporary rebuild ledger. This file maps the current 27-page deck to the visual form best suited to each economic comparison. It does not admit evidence or authorize use of retired estimates.

## Governing rule

Visual variety follows the intellectual object. Use line charts for paths, bars for isolated levels or endpoint contrasts, slope or dumbbell charts for paired changes, difference or forest plots for estimates, heatmaps for matrices and regimes, histograms or densities for distributions, scatterplots for relationships, network diagrams for topology, transaction traces for observable mechanics, and finance-style tables for coefficient patterns. Icons identify concepts; screenshots establish institutional facts; photos belong only where a person, event, or institution is part of the argument. Do not add generic crypto imagery.

No current estimand warrants a surface or three-dimensional chart. Three-dimensional rendering would introduce occlusion and perspective distortion without encoding a necessary third continuous dimension. The explicit verdict for this deck is no 3D.

## Whole-deck diagnosis

The current deck is not uniformly monotonous. The mechanism network, V1 imposed-versus-optional network and exact-state reconstruction sequence use appropriate forms. Monotony is concentrated in the empirical block, where three consecutive slides use grouped bars, and in the appendix, where many slides use prose grids. The highest-value recoveries from the superseded deck are the dual count-and-value transition path, the four-architecture network evolution and, conditional on current evidence, the venue-composition area strip. Retired numeric graphics remain retired even when their visual design was strong.

The saved finance and economics presentations support one economic comparison per slide, restrained annotations and real plots, tables or institutional evidence. They use photographs and screenshots when those items document the episode or institution. They do not support an icon buffet or chart-type variation for its own sake. The older Brunnermeier and Pedersen deck is useful for intellectual sequencing but is a negative density benchmark. The Terra author deck is the stronger benchmark for combining mechanism diagrams, event images, empirical paths and conventional tables.

## Live-performance sequence

1. Open with the question and ask the audience to predict the dominant mechanism.
2. Present one real trade and ask whether they expect direct execution or an intermediary.
3. Reveal the executed cross-venue route through a short local replay.
4. Generalize from one route to continuous vehicle-dominance measures.
5. Morph V1's imposed hub into the optional V2, V3 and V4 networks.
6. Establish the sample and the four mechanisms.
7. Reveal the quarterly transition path.
8. Decompose the transition into USDC and USDT.
9. Test the market-integration explanation with the interaction plot.
10. Return to the opening route and close with three visual takeaways.

The poll must work by show of hands if no audience-response service is available. The transaction replay must run from local data and assets, not a live explorer. An optional local HTML view may animate the trace or support screen sharing, but it is generated from the same manifest and assets as the deck, not maintained as a second presentation.

## Static fallbacks and build discipline

Every animation ends in a complete static composition. The PDF contains the final annotated transaction still, the four-panel architecture strip, the fully accumulated dominance measures and the final interaction plots. A screen recording may accompany the local route replay, but the poster frame must communicate the full result on its own. Each visual is generated from an admitted exhibit or a verified institutional source; hard-coded numeric redraws are not permitted. The compiled PDF remains the portable review artefact, while any HTML or video is a generated live companion from the same source manifest.
